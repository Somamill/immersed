# Required agent design and video tools

This is a standing user preference for every repository, including dot. suite projects. Read this policy before UI or video work. If a required tool is missing, run `python3 .agent-tools/setup.py`; the tools install globally for Codex, outside application runtime dependencies. Node 22+ and Python 3 are required. Use `--browser` to install Chrome for rendered checks as well.

- **Impeccable** (https://github.com/pbakaus/impeccable): load the impeccable skill for interface design, refinement, UX copy and accessibility. Use its audit/critique/polish workflow and run the detector on changed supported frontend files and a local URL when available. Invoke `python3 .agent-tools/run.py impeccable detect <target>`. Findings need review; preserve intentional brand choices and record justified exceptions.
- **Hallmark** (https://github.com/Nutlope/hallmark): load the hallmark skill alongside Impeccable for UI work. Use its craft, accessibility, responsive-layout and truthful-content checks. Use `python3 .agent-tools/run.py hallmark <html-or-directory-or-url> --render` for supported web surfaces. It supplements Impeccable; it does not authorize replacing an established brand with a catalog theme. Apply the relevant principles to native interfaces, but do not claim HTML browser checks validated SwiftUI, UIKit, React Native or Godot screens. Use native checks for those surfaces.
- **Hyperframes** (https://github.com/heygen-com/hyperframes): load the hyperframes skill for product videos, trailers, animated demonstrations and other video tasks. Use its plan, HTML composition, lint, preview and render loop. Invoke `python3 .agent-tools/run.py hyperframes --help`. Install its browser with `hyperframes browser ensure` when rendering. It is a video authoring tool; do not add it as an app runtime dependency merely to satisfy this policy.

For dot. suite apps, `branding/dot/` and the shared dot-brand-kit define the identity. For other projects, preserve their own design rules and product names. Existing app-specific build, signing, release and test requirements still apply. Avoid running unrelated tools for backend-only, dependency-only or documentation-only edits. Report tools used, material findings and any unavailable verification; never claim an unrun check passed.

The global installation makes skills available on this machine. Each checkout contains reproducible setup for another machine. `AGENTS.md` is an agent instruction, not a guarantee that an unrelated editor or human will invoke these tools. This setup uses explicit checks rather than automatic edit hooks; no hook-trust approval is required. Do not publish videos or upload private project content to external services without the user's authorization.
