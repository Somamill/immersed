# Immersed support

For a playback, subtitle, dictionary or accessibility bug, [open a GitHub issue](https://github.com/Somamill/immersed/issues/new/choose). Include the app version, iPhone/iOS version, a public video link if relevant, and what happened. Avoid sharing private account details or credentials.

For private support, privacy or security requests, email [k4jenx@gmail.com](mailto:k4jenx@gmail.com). Do not post personal information in a public GitHub issue. The project is an independent open-source app; YouTube video availability depends on its owner and YouTube.
